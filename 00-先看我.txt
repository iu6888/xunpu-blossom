蟳埔花事 · 泉州城市礼物
使用说明
================================================

【这是什么】

一个完整可以跑起来的网站，包含五部分：

  前台      6 件文创产品的展示与下单
  花间游戏  9 款小游戏（含南音 / 花灯 / 德化瓷），通关可领 ¥5 券
  顾客账户  手机号注册 / 登录 / 我的订单 / 我的券
  结算      优惠券抵扣、运费规则、下单
  管理后台  商品、订单、顾客、优惠券、询价、数据统计

所有数据存在本地，不连接任何外部服务。


【怎么启动】

  1. 双击 start.bat
  2. 浏览器会自动打开 http://localhost:3000
  3. 管理后台 http://localhost:3000/admin/

     账号  admin
     密码  xunpu2026

  Mac / Linux 用户：在终端执行 ./start.sh


【小游戏和优惠券怎么玩】

  打开 http://localhost:3000/games/
  选任意一款，通关后弹窗给出券码，点一下就能复制。

  券的默认规则：
    面额 ¥5，满 ¥59 可用，7 天内有效
    同一玩家同一游戏每天 1 张，同一 IP 每天最多 3 张
    游客按昵称记录，登录后按账号记录

  用券：购物车 → 结算 → 输入券码 → 核对券码 → 金额自动抵扣。
  看券：account.html#coupons 的「我的券」，登录后会按账号自动带出。
  作废：后台「优惠券」里可以按状态筛选、搜索和手动作废。

  想改面额 / 门槛 / 有效期，见 .env.example 里的 GAME_COUPON_*。


【前提条件】

电脑上任选其一：

  - Node.js 22.5 或更高版本（推荐）
    打开 https://nodejs.org 下载 LTS 版本，
    一路「下一步」装完即可。

  - Docker Desktop
    打开 https://www.docker.com/products/docker-desktop/
    装完并启动 Docker 即可，不用另外装 Node。

start.bat 会自己判断：有 Node 就用 Node，
没有就调用 Docker；两样都没有时会提示安装地址。

如果这个包里带 runtime 文件夹（便携版），
则不需要另外安装，双击就能用。


【第一次进去，建议先做三件事】

  1. 后台「设置 → 账号」改掉默认密码
  2. 后台「商品」核对价格与库存
  3. 前台随便下一单，走一遍完整流程（可以先去玩一局游戏拿券）


【数据存在哪儿】

  data\xunpu.db   一个文件就是全部数据
                  （商品、订单、顾客、询价、优惠券）

  删掉这个文件再启动，会恢复成初始的 6 件商品。
  要备份，复制这个文件即可。
  要搬走，把整个文件夹拷贝过去就行。


【想放到公网上】

  deploy\install.sh 是一键部署脚本，
  需要一台 Ubuntu 或 Debian 的服务器。

  用法见 README.md 的「部署」章节，
  或者 Dockerfile / docker-compose.yml 用容器跑。


【怎么关掉】

  在黑窗口里按 Ctrl+C，或者直接关掉窗口。
  关掉之后网站就打不开了，重新双击 start.bat 即可。


【改端口】

  默认 3000。想换的话用记事本打开 start.bat，
  把 set PORT=3000 改成别的数字再保存。
